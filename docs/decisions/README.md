# Architecture Decision Records (ADRs)

Wesentliche Entscheidungen über Architektur und Datenverantwortung
werden in dieser Mappe dokumentiert. Jede ADR hält Kontext, Entscheidung,
Folgen, Alternativen und offenen Freigabestatus fest.

## Statusregeln

- **Proposed:** dokumentierter Vorschlag oder Bestandsaufnahme ohne
  bestätigte Produkt-/Architekturfreigabe.
- **Accepted:** Entscheidung mit verantwortlicher Freigabe und Datum.
- **Superseded:** durch eine konkrete neuere ADR abgelöst.

Die Einträge 001–005 dokumentieren zuerst die technische Ausgangslage.
Sie sind **nicht allein durch Anlage dieser Dateien freigegeben**.
